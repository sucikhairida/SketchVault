# SketchVault

SketchVault is a high-performance, auto-scaling platform for real-time data management and synchronization of design assets across multiple systems.

With SketchVault, you get a lightweight tool that stays out of your way.

**What you get**

- SketchVault is a high-performance, auto-scaling
- platform for real-time data management
- and synchronization of design assets

- python

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/SketchVault.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
